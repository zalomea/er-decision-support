# Synthetic clinical narratives

All files in `cases/` and the example reports at this level are fictional and generated for software testing and demonstration. They do not describe real people and are not expert-reviewed clinical ground truth. The priority values in filenames describe the generator's intended ordering, not validated diagnoses or triage outcomes.

Do not use these fixtures—or outputs from the demo—to guide real patient care. See the project [safety and privacy notes](../README.md#safety-privacy-and-licensing).
